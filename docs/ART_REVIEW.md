# Phase 3.0 · 室内美术样板验收

本轮只做室内样板与双人默认服装的四向站立、行走整理。庭院沿用阶段 2.5 原图；未经视觉方向确认，不批量替换其他家具或服装。

## 接入与替换

- `src/game/artCatalog.ts` 记录每个地图图层的纹理、世界坐标、像素尺寸、深度和美术状态；床的图像与床前沿可以单独替换。
- 室内家具的碰撞格集中在 `homeFurniture`，玩家移动和 NPC A* 使用同一张碰撞地图。视觉资源不能擅自改变这些格子；需要调整时同时检查 `anchors.ts` 的互动位置。
- `src/game/characterAssets.ts` 记录每人 `default` 与 `alternate` 服装槽。当前 `alternate: null`，没有可选第二套。动画根据实际纹理键播放，未来换装无需改 NPC 行为。
- Phaser 继续使用最近邻采样、脚底 `(0.5,1)` 原点与整数镜头倍率；角色素材不拉伸。角色脚部碰撞保持 8×4 游戏像素。
- 新 PNG 导入前运行 `python3 scripts/validate_art.py`、`npm run typecheck`、`npm test`、`npm run build`。PNG 原图必须保留 1:1 像素边界、透明背景及约定的帧顺序。

## 尚未完成的正式美术

两人当前前 16 帧虽可四向行走，发型、面部和布料细节仍是低分辨率设计草稿；第 16–31 帧的坐下、牵手、拥抱、睡觉、对话等为临时动作，不是正式同步动画。第二套服装没有照片参考，也没有素材。室内除了床样板外的沙发、书桌、书架、衣柜、窗帘和其他物件，以及整个庭院仍沿用上阶段原创临时稿。

达到概念图那种细节密度需要经授权的两人原始照片、可逐帧检查的 32×48 人物原画、按实际地图坐标拆分的家具 RGBA PNG 和遮挡层，并由像素美术逐件修稿。概念图不能通过简单缩小或裁切转为合格的 16×16 游戏素材。
