# Phase 3.5 渲染与原始素材密度验收

## 修改前测量

1194×834 Chromium 触屏视口中，游戏 Canvas 的 CSS 和 backing 尺寸均为 1150×734，即使设备像素比为 2。室内镜头倍率为 1.9114583333。WebGL MAG_FILTER 值 9728（NEAREST），Canvas 的 CSS image-rendering 已为 pixelated：线性插值不是本轮确认的原因。没有有损 GPU 纹理压缩或全局模糊滤镜。

室内游戏底图只有 480×384，来自 1402×1122 的离线最近邻缩图，木纹、花纹与小物细节已被丢弃。庭院旧素材为 704×544 的程序绘制稿，没有可恢复的高清源图。因此仅改滤镜或放大旧 PNG 无法满足细节要求。

## 坐标与分辨率

- 世界始终保持 16×16 网格；室内 480×384 世界单位，庭院 704×544。碰撞、A*、角色 40×60 帧尺寸、座位和床铺锚点不变。
- 纹理像素和世界单位分开：室内直接加载 1402×1122 原图，以 displayWidth=480、displayHeight=384 映射到原世界范围；沙发前景从同一原图的相同归一化坐标裁出，保持原遮挡深度。
- 秋季庭院原生纹理为 1427×1102，包含重新绘制的草叶、石板、木纹、屋顶、花圃、门窗；不是旧图放大、加噪声或锐化。原碰撞网格和位置保留。长椅前景独立提供，纪念树树冠独立绘制。其余季节继续原素材，等待分批重制。
- 新 Canvas 使用物理像素：DPR 2 时为 2300×1468，CSS 显示仍是 1150×734。Scale Manager 的 zoom=1/density 同时维护指针坐标换算。ResizeObserver 在横竖屏变化时重新计算。密度上限为 2，控制高 DPR 手机的像素填充量。
- 室内默认采用物理像素整数镜头倍率，完整房间居中，允许留边；DPR 2 的测量视口倍率为 3，即 CSS 1.5 倍。庭院继续跟随，使用相同 CSS 视野对应的整数物理倍率。极小屏不足 1 倍时允许等比缩小以完整显示房间。
- 最近邻保持原配置。人物、床铺睡眠与行走素材未重绘；新场景原生像素密度高于人物，显示大小保持不变，最终像素颗粒协调程度仍需美术验收。

## 可复现对照

`/clarity-review/` 提供修复前后真实 Phaser 截图、同位置局部放大、人物比例对照与 measurements.json。两版在同一 1194×834、DPR 2 触屏视口中录制；室内都以 CSS 1.5 倍、庭院都以 CSS 2 倍显示，世界坐标相同。因此比较没有通过改变人物大小或镜头距离制造清晰度差异。

仅用于验收的参数：`render=legacy` 使用旧 Canvas；`sceneArt=legacy` 选择旧素材；`sampleZoom=1.5` 固定 CSS 镜头倍率。常规游戏不带这些参数，使用自动适配。

## 设备与美术限制

Chromium 的 DPR 2 和触屏模拟不是实际 iPad Safari。Safari 真机的像素观感、持续触控、帧率与系统手势仍需人工验收。当前庭院高密度版本先覆盖秋季，其他季节保留旧素材。床铺独立动画图层沿用已验收版本，未为追求背景细节修改人物与睡眠动作。环境资源仍属于 AI 辅助可玩样板，未宣称全部家具都已成为逐件手绘透明资源。
