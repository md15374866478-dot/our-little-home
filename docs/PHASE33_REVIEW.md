前 16 帧逐像素沿用已获认可的 V3.1 四方向行走候选图集：下、左、右、上各四帧，每组第 2 帧作待机。后 16 帧分别是坐下／起身（16–19）、牵手／松手（20–23）、拥抱／结束（24–27）、躺下／睡眠／起床（28–31）。图集边缘是透明或全不透明像素，脚底基线一致，Phaser 以最近邻采样和 `(0.5, 1)` 原点显示，不在运行时拉伸。两个角色的第二套服装槽保持 `null`，没有伪装成已完成资源。

`scripts/prepare_characters_v33.py` 从独立源图重建图集，`scripts/validate_art.py` 检查尺寸、Alpha、脚底基线、空帧和前 16 帧的完全一致性。设定板是视觉参考，没有直接从合成图随意裁切人物。

## 实际游戏集成

- `characterAssets.ts` 将新版图集设为两人的默认服装；NPC 行为、角色 ID、场景状态沿用原接口。
- `characterAnimations.ts` 管理四向待机／行走、坐下、起身、牵手、松手、拥抱、躺下、睡眠、起床及对话转向。拥抱和睡眠循环使用两个相邻动作帧；其余过渡在移动或退出后返回四向状态。
- 牵手时门都维持选定的左侧或右侧；转向不再突然绕到另一侧。家具附近侧面放不下时使用前后队形，NPC 寻路仍走原共享碰撞网格。马硕脚部与门都保持最小间距，避免穿模。
- 双人坐下、睡觉仍先走到家具外的锚点；床被与沙发前缘继续使用已验收的前景层。起身和起床动画与安全返回锚点的时间对齐。
- `/?preview=home` 从同一个可玩 Phaser 场景的室内安全位置开始，供 iPad 验收。普通入口仍从庭院门口出生；室内外切换逻辑不变。

## 预览和验证

独立预览站的 `/art-review/` 展示两张完整图集和从 1194×834 触屏模拟浏览器截取的真实游戏画面。可从该页进入 `/?preview=home`，用方向键或触控方向键移动，并点「与门都互动」逐项验证跟随、牵手、拥抱、坐下、睡觉、自由活动。截图只是验收索引，互动须在游戏内体验。

本轮运行 `npm run typecheck`、`npm test`、`npm run build`、`python3 scripts/validate_art.py`，并用 Chromium 触控模拟器走室内外、菜单、行为切换、坐睡、画面尺寸变化与控制台检查。真实 iPad Safari 横屏、持续触摸、旋转和实际帧率仍需用户设备验收。

## 尚未完成的美术

用户已确认角色造型和整体效果，本轮不再大规模重绘。当前动作源图是原创 AI 辅助图，经离线整理成可玩的固定帧精灵；尚未经像素画师按两人的真人照片逐帧手工精修。部分动作使用两帧循环，细微度仍可继续提高。第二套服装没有所需照片与正式逐帧素材，仍为空。室内和庭院保持上一阶段的已验收画面，本轮不把底图说成逐件手绘家具资源。
