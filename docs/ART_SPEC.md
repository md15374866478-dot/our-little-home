# Our Little Home · 美术与角色资源规范（阶段 2.5–3.0）

## 统一规格

- 地图网格仍为 16×16；室内 30×24，庭院 44×34。碰撞与互动锚点沿用原地图数据。
- 角色单帧 32×48 RGBA PNG；8 列、4 行，共 32 帧，整图 256×192。底部中央为统一脚底锚点 `(0.5, 1)`；脚部碰撞仍按游戏中的 8×4 区域计算。
- 色板以深棕轮廓、暖木色、奶油白、鼠尾草绿和柔和黄光为基础。角色避免纯黑大面积填充，并用三档明暗区分头发和布料。
- Phaser 使用 nearest-neighbor、整数镜头倍率和像素对齐。图片不进行非整数拉伸。
- 地图原画按 1 游戏像素绘制并以透明遮挡层叠放；小摆件不改变碰撞格。

角色资源由 `characterAssets.ts` 统一预载，动作由 `characterAnimations.ts` 映射；换装时添加同规格 PNG 和资源配置即可，行为控制器只引用角色 ID。正式图集须逐帧检查透明背景、人物边界和脚底位置。

阶段 3.0 将默认与备用服装槽显式分开。`alternate: null` 表示第二套尚无素材；切换到不存在的资源会失败且不改动角色。室内床样板拆为底图、透明床图、床前沿和其他前景，具体尺寸与待制作清单见 [ART_REVIEW.md](ART_REVIEW.md)。

## 本次参考图与已知限制

对话中提供的设定图是含文字、装饰背景和大小不一人物示意的合成图，并非可直接导入的透明精灵表。当前工作区没有该附件的原始文件，因此无法程序化测量它的原始尺寸、Alpha 通道或逐帧边界；本次没有从图中裁切或复制像素。`scripts/draw_characters.py` 生成的两名角色是基于可见特征重新绘制的原创**临时可玩稿**，第二套服装和照片级相似度仍待原始照片及人工美术制作。

精修正式美术建议提供两人的已授权原始照片、独立透明角色原画或按上述 32×48 规范制作的逐帧 PNG。环境参考图只用于材质密度与氛围方向，不直接作为地图资源。
