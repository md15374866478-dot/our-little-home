# Lucky 宠物模组验收

开发分支：`feat/lucky-pet-integration`，基于 Phase 3.5 的现有角色与高清场景。人物、室内和庭院资源没有重绘，GitHub Pages 工作流没有修改。

## 已接入游戏

Lucky 在室内和庭院自主靠近马硕或门都，并在活动间停留。点击 Lucky 或右侧宠物按钮，可选择跟随马硕、跟随门都、抚摸、抱起、放下、玩球、喂食、回窝睡觉和自由活动。玩球包含抛物线投球、奔跑寻找和带回；喂食显示点心碗；入窝使用独立趴卧／闭眼帧和狗窝前沿遮挡。场景切换保留跟随或抱起意图，在淡出期间重新安排安全位置。

宠物 A* 复用现有碰撞地图，并叠加人物占位。移动逐步校验，阻挡时限频重规划，超时恢复待机。抱起后只有明确的放下动作才在安全地面放置，普通寻路失败不瞬移。人物移动和自动寻路避开 Lucky 及狗窝。玩家发起双人动作时 Lucky 先让到旁边，保留原有牵手、拥抱、坐下和睡眠功能。

## 验证与边界

类型检查、29 项自动测试和生产构建用于发布检查。新增宠物测试覆盖命令中断、寻路失败恢复、绕过家具、人物占位及网格边界上的安全放下。此前 Chromium DPR 2 实机流程走通室内抚摸、抱起、放下、喂食、入窝睡眠、跟随门都、跨场景跟随、庭院抛球取回，录制截图和视频时没有页面错误；原双人动作与视口缩放也完成回归。

`/lucky-review/` 提供真实图集播放和实机演示；普通游戏入口 `/` 和室内入口 `/?preview=home` 均包含 Lucky。抱起、抚摸采用原人物姿态和宠物动作组合，尚无专用抱宠手臂动画。当前工作区未找到 Lucky 原始照片文件，因此图集按附带设计图特征重新制作，尚未做原始照片的逐帧相似度核验。真实 iPad Safari 横屏、持续触控和设备帧率仍待人工验收。
